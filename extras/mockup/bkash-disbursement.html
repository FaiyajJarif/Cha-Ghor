Simulation only. This page is a teaching mockup for the Cha Ghor project. It is not connected to bKash, sends no SMS, and moves no money. The “bKash” panel imitates the shape of a corporate disbursement portal so the workflow can be explained; it is not bKash software and every figure is invented.

Payroll → worker request → approval → bKash bulk disbursement

The route ~800 RMG factories actually use: the employer pre-funds a corporate disbursement account, uploads a file of wallet numbers and amounts, and bKash credits every wallet in one run.
